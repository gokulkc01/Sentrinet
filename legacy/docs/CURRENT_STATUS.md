# SentryNet — Current Status (updated May 18, 2026)

This file lists the immediate status, recent progress, artifacts produced, and concrete next steps to finish the project to a reproducible, publication-ready state.

## Quick status
- Plotting and analysis scripts added; multi-condition plots generated and saved to `results/plots/`.

## What works now
- Training pipeline (MAPPO) runs and saves checkpoints.
- Evaluation pipeline (`run_trained.py`) runs headless and visual modes.
- Plotting and CSV aggregation scripts produce repeatable figures.
- Trust pipeline no longer compares against global ground truth (uses consensus/local estimates).

## Known remaining issues
1. Seed variance: need 5+ seeds per configuration for robust claims.
2. PyBullet stability: dashboard should recover gracefully from physics server disconnects.
3. Per-step trust logging: instrument evaluation to write per-step trust for real dynamics plots.
4. Retraining: need to retrain weak seeds or run validation harness at higher step counts.
